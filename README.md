## 🛠️ Стек технологий и навыки

### 📊 Анализ данных, BI & Data Science
* **ETL & Моделирование:** Power Query (очистка и преобразование данных), Power Pivot (построение сложных моделей данных, связи между таблицами, расчеты DAX).
* **Python для Data Science:** Pandas (манипуляция, агрегация и очистка данных), NumPy (векторизованные вычисления и математические операции), Matplotlib (построение графиков и разведочный анализ данных — EDA).
* **Базы данных (SQL):** PostgreSQL, Microsoft SQL Server, MySQL (проектирование сложных запросов, выборка и структурирование данных).
* **Визуализация & BI:** Power BI (интерактивные дашборды и отчеты), MS Visio (проектирование ER-диаграмм и связей в БД), MS Excel (продвинутый бизнес-анализ).
* **Документация:** MS Word (подготовка ТЗ, регламентов и аналитических отчетов).

### 🐍 Python Разработка & Автоматизация
* **Core & Standard Library:** Многопоточность (`threading`, `queue`, `concurrent.futures`), работа с файловой системой (`os`, `shutil`, `tempfile`), логирование (`logging`), алгоритмы и структуры данных (`hashlib`, `collections`).
* **GUI (Интерфейсы):** Tkinter (ttk, scrolledtext), Pillow (обработка изображений).
* **Разработка ПО:** Проектирование системных утилит (поиск дубликатов, хэширование файлов), оптимизация производительности (ThreadPoolExecutor).

### 🌐 Frontend Разработка
* **Веб-технологии:** HTML5, CSS3.
* **JavaScript:**  Модульный подход и методы работы с массивами/объектами.

### ⚙️ Инструменты & DevOps
* **Операционные системы:**  Windows и Linux.
* **Контроль версий:** Git, GitHub (стандарты коммитов Conventional Commits).
* **Среда разработки:** VS Code, CLI (работа с терминалом).
