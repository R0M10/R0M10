### 📊 Анализ данных, BI & Data Science
* **ETL & Моделирование:** Power Query (очистка и преобразование данных, подключение к PostgreSQL/Jira, построение плоских витрин), Power Pivot (построение сложных моделей данных, связи между таблицами, расчеты DAX).
* **Python для Data Science:** Pandas (манипуляция, агрегация и очистка данных), NumPy (векторизованные вычисления и математические операции), Matplotlib (построение графиков и разведочный анализ данных — EDA).
* **Базы данных (SQL):** PostgreSQL, Microsoft SQL Server, MySQL (проектирование сложных запросов, выборка и структурирование данных).
* **Визуализация & BI:** Power BI (интерактивные дашборды, модель «звезда», DAX-меры, интеграция с PostgreSQL/Jira, scheduled refresh), MS Visio (проектирование ER-диаграмм и связей в БД), MS Excel (продвинутый бизнес-анализ).
* **Документация:** MS Word (подготовка ТЗ, регламентов и аналитических отчетов).

### PowerBI
* **Корпоративный дашборд сервисной аналитики** — интерактивная отчётность для сервисной службы: операционные метрики и KPI по обслуживанию оборудования. Данные из внутренней Jira-системы через PostgreSQL-реплику (прямое подключение), предварительно сформирована плоская витрина + локальный календарь и справочники. Модель — схема «звезда», расчёты на DAX.
  * **Класс метрик:** длительность ведения запросов (MTTR, время реакции, время в статусах), классификация отказов и оборудования, разрезы по организациям и исполнителям, динамика потока и backlog.
  * **Стек:** `Power BI` · `PostgreSQL` · `Jira` · `DAX` · `Power Query` · `Import + scheduled refresh`.
  * **Статус:** внутренний проект, код и данные не публикуются.
